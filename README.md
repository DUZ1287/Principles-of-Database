## 🔑 面试高频知识点

### 必会

| 知识点 | 一句话记忆 |
|:---|:---|
| SELECT 执行顺序 | FROM→WHERE→GROUP→HAVING→SELECT→ORDER→LIMIT |
| 7 种 JOIN | 内连接+左/右外+左/右独有+全外+全外去交集 |
| GROUP BY + HAVING | WHERE 过滤行，HAVING 过滤组 |
| B+ 树 vs B 树 | 矮胖、叶子链表、IO 少 |
| 聚簇索引 vs 二级索引 | 聚簇存数据，二级存主键（回表） |
| 联合索引最左前缀 | 像排队，必须从最左开始 |
| ACID 实现机制 | 原子=Undo，持久=Redo，隔离=锁+MVCC |
| 四种隔离级别 | MySQL 默认 RR |
| MVCC 实现 | 隐藏字段+版本链+ReadView |
| Redo Log vs binlog | Redo=引擎层持久化，binlog=Server层复制 |

### 核心概念速记

| 概念 | 一句话记忆 |
|:---|:---|
| 回表 | 拿着主键再查一遍 |
| 覆盖索引 | 全程在索引里，不用回表 |
| Buffer Pool | 内存里的数据缓存，减少磁盘 IO |
| 间隙锁 | 锁住空隙，防止插队（幻读） |
| 主从复制 | 主库写日志，从库抄作业 |
