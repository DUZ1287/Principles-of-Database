# 函数与子查询

## 一、函数（P32~P42）

### 1.1 数值函数

```sql
ABS(-10)         → 10      -- 绝对值
CEIL(3.14)       → 4       -- 向上取整
FLOOR(3.14)      → 3       -- 向下取整
ROUND(3.141, 2)  → 3.14    -- 四舍五入
TRUNCATE(3.146,2)→ 3.14    -- 截断（不四舍五入）
MOD(10, 3)       → 1       -- 取余
RAND()           → 0~1随机数
```

### 1.2 字符串函数

```sql
CONCAT('Hello',' ','World')  → 'Hello World'
CONCAT_WS('-','2024','01')   → '2024-01'
SUBSTR('Hello World', 1, 5)  → 'Hello'
LENGTH('你好')               → 6（字节，UTF8 中文 3 字节）
CHAR_LENGTH('你好')          → 2（字符数）
REPLACE('Hello','l','L')     → 'HeLLo'
TRIM('  hello  ')            → 'hello'
LPAD('1',3,'0')              → '001'
INSTR('Hello','el')          → 2
```

### 1.3 日期函数

```sql
NOW()                              → 当前日期时间
CURDATE()                          → 当前日期
DATE_FORMAT(NOW(), '%Y-%m-%d')     → 格式化
DATEDIFF('2024-12-31', NOW())      → 相差天数
DATE_ADD(NOW(), INTERVAL 1 YEAR)   → 一年后
LAST_DAY(NOW())                    → 本月最后一天
```

### 1.4 流程控制函数

```sql
-- IF：二选一
SELECT IF(salary > 5000, '高薪', '低薪') FROM employees;

-- IFNULL：处理 NULL
SELECT IFNULL(commission_pct, 0) FROM employees;

-- CASE WHEN：多条件判断
SELECT
  CASE
    WHEN salary > 20000 THEN 'A级'
    WHEN salary > 10000 THEN 'B级'
    ELSE 'C级'
  END AS 等级
FROM employees;
```

### 1.5 五大聚合函数（面试常考）

| 函数 | 作用 | NULL 处理 |
|---|---|---|
| `COUNT(*)` | 统计总行数 | 包含 NULL 行 |
| `COUNT(列)` | 统计非 NULL 行 | 忽略 NULL |
| `SUM(列)` | 求和 | 忽略 NULL |
| `AVG(列)` | 平均值 | 忽略 NULL |
| `MAX(列)` / `MIN(列)` | 最大/最小值 | 忽略 NULL |

> `COUNT(*)` 和 `COUNT(1)` 效率相同，都比 `COUNT(列)` 快（后者要判断 NULL）。

### 1.6 GROUP BY 与 HAVING

```sql
-- GROUP BY：按部门统计平均薪资
SELECT department_id, AVG(salary) avg_sal
FROM employees
GROUP BY department_id;

-- HAVING：过滤分组后的结果（WHERE 过滤分组前）
SELECT department_id, AVG(salary) avg_sal
FROM employees
GROUP BY department_id
HAVING avg_sal > 8000;
```

**WHERE vs HAVING**：

| 对比 | WHERE | HAVING |
|---|---|---|
| 过滤时机 | 分组前 | 分组后 |
| 能否用聚合函数 | ❌ 不能 | ✅ 能 |
| 执行顺序 | 先 | 后 |

## 二、子查询（P43~P48）

### 2.1 子查询分类

| 分类 | 说明 | 示例 |
|---|---|---|
| **单行子查询** | 结果只有一行 | `WHERE salary > (SELECT AVG(salary) FROM employees)` |
| **多行子查询** | 结果有多行 | `WHERE dept_id IN (SELECT dept_id FROM ...)` |
| **相关子查询** | 子查询引用外查询的列 | `WHERE salary > (SELECT AVG(salary) FROM employees e2 WHERE e2.dept_id = e1.dept_id)` |

### 2.2 多行子查询操作符

| 操作符 | 含义 | 示例 |
|---|---|---|
| `IN` | 等于任意一个 | `WHERE dept_id IN (SELECT ...)` |
| `ANY` / `SOME` | 大于/小于任意一个 | `WHERE salary > ANY (SELECT ...)` |
| `ALL` | 大于/小于所有 | `WHERE salary > ALL (SELECT ...)` |

### 2.3 EXISTS

```sql
-- EXISTS：子查询有结果则为 TRUE
SELECT * FROM employees e
WHERE EXISTS (
  SELECT 1 FROM departments d WHERE d.dept_id = e.dept_id
);
```

**IN vs EXISTS**：
- `IN`：先执行子查询，再用结果过滤（适合子查询结果集小）
- `EXISTS`：对外查询每行执行子查询（适合外查询结果集小）

## 三、容易出错的地方

1. **聚合函数不能用在 WHERE 中**：`WHERE AVG(salary) > 5000` 是错的，要用 HAVING
2. **GROUP BY 和 SELECT 不匹配**：SELECT 中非聚合列必须出现在 GROUP BY 中
3. **子查询返回多行时不能用 `=`**：要用 `IN` 或 `ANY`
4. **NULL 参与运算**：任何值与 NULL 运算都是 NULL
