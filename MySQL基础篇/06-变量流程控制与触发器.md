# 变量、流程控制与触发器

## 一、变量（P83~P85）

### 1.1 系统变量

```sql
-- 查看系统变量
SHOW VARIABLES LIKE 'autocommit';
SELECT @@transaction_isolation;

-- 设置系统变量
SET GLOBAL max_connections = 500;     -- 全局（所有会话生效）
SET SESSION autocommit = 0;          -- 当前会话
```

### 1.2 用户变量

```sql
-- 赋值
SET @name = '张三';
SET @count = (SELECT COUNT(*) FROM employees);

-- 使用
SELECT @name;
```

### 1.3 局部变量（BEGIN...END 内部）

```sql
DELIMITER //
CREATE PROCEDURE sp_demo()
BEGIN
  DECLARE total INT DEFAULT 0;  -- 声明局部变量
  SELECT COUNT(*) INTO total FROM employees;
  SELECT total;
END //
DELIMITER ;
```

| 变量类型 | 作用域 | 前缀 | 定义位置 |
|---|---|---|---|
| 系统变量 | 全局/会话 | `@@` | 随时可设 |
| 用户变量 | 当前会话 | `@` | 随时可设 |
| 局部变量 | BEGIN...END 内 | 无 | 必须 DECLARE |

## 二、流程控制（P86~P91）

### 2.1 IF

```sql
-- 语法
IF 条件1 THEN 语句1;
ELSEIF 条件2 THEN 语句2;
ELSE 语句3;
END IF;
```

### 2.2 CASE

```sql
-- 简单 CASE
CASE 表达式
  WHEN 值1 THEN 语句1;
  WHEN 值2 THEN 语句2;
  ELSE 语句3;
END CASE;
```

### 2.3 循环

```sql
-- WHILE 循环
WHILE 条件 DO
  循环体;
END WHILE;

-- LOOP + LEAVE（类似 break）
loop_label: LOOP
  IF 条件 THEN LEAVE loop_label; END IF;
  循环体;
END LOOP;

-- REPEAT（类似 do...while）
REPEAT
  循环体;
UNTIL 条件
END REPEAT;
```

### 2.4 游标（Cursor）

```sql
-- 遍历查询结果集
DECLARE cur CURSOR FOR SELECT name, salary FROM employees;
OPEN cur;
FETCH cur INTO @name, @salary;  -- 逐行获取
-- 循环处理...
CLOSE cur;
```

## 三、触发器（P92~P93）

触发器是当表发生 INSERT/UPDATE/DELETE 时**自动执行**的一段逻辑。

### 3.1 创建触发器

```sql
DELIMITER //
-- 在 employees 表插入数据后，自动记录到日志表
CREATE TRIGGER trg_after_insert_emp
AFTER INSERT ON employees
FOR EACH ROW
BEGIN
  INSERT INTO emp_log (emp_name, action, action_time)
  VALUES (NEW.first_name, 'INSERT', NOW());
END //
DELIMITER ;
```

### 3.2 NEW 和 OLD 关键字

| 触发事件 | NEW | OLD |
|---|---|---|
| INSERT | 新插入的行 | 无 |
| DELETE | 无 | 被删除的行 |
| UPDATE | 修改后的值 | 修改前的值 |

### 3.3 BEFORE vs AFTER

| 类型 | 时机 | 典型场景 |
|---|---|---|
| BEFORE | 操作前 | 数据校验、自动填充 |
| AFTER | 操作后 | 记录日志、同步数据 |

## 四、容易出错的地方

1. **用户变量 vs 局部变量**：用户变量用 `@` 前缀，局部变量不用
2. **触发器性能**：大量 DML 操作时触发器会拖慢性能
3. **触发器调试困难**：出了问题不好排查
4. **递归触发器**：一个触发器触发另一个，可能导致死循环
