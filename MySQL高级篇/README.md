## 核心概念速记卡片

| 概念 | 一句话记忆 |
|---|---|
| B+ 树 | 矮胖树，叶子存数据，IO 次数少 |
| 聚簇索引 | 数据即索引，索引即数据 |
| 回表 | 拿着主键再查一遍 |
| 覆盖索引 | 全程在索引里，不用回表 |
| 最左前缀 | 联合索引像排队，必须从最左开始 |
| Buffer Pool | 内存里的数据缓存，减少磁盘 IO |
| Redo 日志 | 先记账后干活，崩溃能恢复 |
| Undo 日志 | 时光机，能回滚，支撑 MVCC |
| MVCC | 多版本快照，读写不阻塞 |
| 间隙锁 | 锁住空隙，防止插队（幻读） |
| 两阶段提交 | 先准备再提交，保证一致性 |
| binlog | 变更账本，主从复制靠它 |
| 主从复制 | 主库写日志，从库抄作业 |
